# Supply Chain Management & Performance Analysis

## 📌 Project Overview

This project focuses on analyzing supply chain data to understand business performance across sales, revenue, inventory, products, suppliers, shipping, and logistics.

## 🎯 Objectives

* Analyze total sales and revenue performance
* Monitor product and inventory performance
* Evaluate supplier and shipping performance
* Analyze lead time and delivery-related metrics
* Identify inventory risks and business trends
* Generate actionable insights using data

## 🛠️ Tools & Technologies

* Excel
* MySQL
* Python
* Power BI

## 📊 Key KPIs

* Total Revenue: 577,604.86
* Products Sold: 46,099
* Average Order Quantity: 49.22
* Average Lead Time: 17.08 Days

## 🔍 Key Analysis

The analysis covers product performance, sales trends, revenue generation, stock availability, supplier performance, shipping costs, lead time, and defect rates.

## 💡 Outcome

The project provides a clear view of supply chain performance and helps identify areas for improving inventory management, supplier efficiency, and overall operational performance.
